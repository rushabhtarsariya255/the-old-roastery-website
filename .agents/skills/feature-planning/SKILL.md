# Feature planning
1. Clarify the user outcome and acceptance criteria.
2. Inspect the existing code paths and reuse opportunities.
3. Break the feature into UI, domain, API, persistence, analytics, and testing tasks as relevant.
4. List files likely to change and any new files.
5. Identify edge cases, security/privacy concerns, accessibility, and performance risks.
6. Identify dependencies and migrations separately.
7. Present plan, risks, verification steps, and ask for explicit approval before edits.
