# Premium UI builder
1. Inspect current UI, design tokens, component library, and reference assets.
2. Define page hierarchy, responsive behavior, and reusable component boundaries.
3. Propose typography, spacing, color, radii, elevation, and motion tokens consistent with the product.
4. Specify loading, empty, error, disabled, hover, focus, and pressed states.
5. Present a file-level plan and wait for approval before editing.
6. Implement using existing dependencies and conventions.
7. Verify responsive layouts, keyboard/accessibility behavior, and reduced motion where possible.
