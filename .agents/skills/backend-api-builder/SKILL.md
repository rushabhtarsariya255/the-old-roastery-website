# Backend/API builder
1. Inspect routing, middleware, auth, data access, error handling, and test patterns.
2. Define request/response contracts and validation rules.
3. Check authentication and authorization requirements.
4. Consider idempotency, pagination, rate limits, timeouts, transactions, and observability.
5. Present files, dependencies, schema changes, and tests; wait for approval.
6. Implement only approved scope and add tests.
7. Report commands and verified outcomes.
