# React Native builder
1. Detect bare React Native vs Expo and inspect installed versions.
2. Inspect navigation, state, styling, native modules, and platform-specific files.
3. Plan iOS/Android behavior, safe areas, keyboard handling, accessibility, and list performance.
4. Flag native dependency or Pod/Gradle changes for separate approval.
5. Present the implementation plan and wait for approval.
6. Implement and run available lint, typecheck, tests, and approved platform builds.
7. Report platform-specific results and limitations.
