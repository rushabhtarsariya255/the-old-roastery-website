# Code review
1. Understand the intended behavior and changed-file scope.
2. Trace relevant call sites and data flow.
3. Prioritize findings by severity and likelihood.
4. Check correctness, security, error handling, race conditions, accessibility, performance, and tests.
5. Cite file paths and line ranges when available.
6. Report actionable findings first; distinguish definite bugs from suggestions.
7. Do not edit files during review.
