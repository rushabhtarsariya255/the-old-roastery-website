# Frontend and premium UI
- First inspect existing design tokens, components, routing, styling, and responsive breakpoints.
- Deliver a coherent premium design system, not disconnected screens.
- Prioritize hierarchy, typography, spacing, alignment, contrast, and purposeful whitespace.
- Cover responsive, loading, empty, error, disabled, focus, hover, and pressed states.
- Use semantic HTML and accessible labels; support keyboard navigation.
- Use motion sparingly and respect reduced-motion preferences.
- Avoid generic template layouts and decorative effects that reduce clarity.
- Reuse existing components and tokens; propose new dependencies before installation.
