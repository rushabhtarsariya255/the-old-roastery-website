# General engineering
- Inspect the existing implementation before changing it.
- Match the repository's language, framework, package manager, conventions, and architecture.
- Prefer the smallest safe change that solves the requirement.
- Do not fabricate APIs, commands, dependencies, environment variables, or test results.
- Add tests for changed behavior when a test framework exists.
- Explain assumptions, risks, and trade-offs.
- Main `AGENTS.md` approval rules always apply.
